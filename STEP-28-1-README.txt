Этап 28.1: восстановление личных диалогов после F5

Исправлено:
- личный чат с сообщениями сохраняется в списке ниже групп после обновления страницы;
- сервер отдаёт для списка только последнее видимое сообщение, а не всю историю;
- удалённый только у пользователя чат после F5 не возвращается;
- после нового сообщения такой диалог снова появляется;
- полная история загружается только при открытии чата.

Новых миграций нет.

После распаковки:
1. Перезапустить сервер и фронтенд.
2. Выполнить npm test в обеих папках.
3. Выполнить npm run build во фронтенде.
