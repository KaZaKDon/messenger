Этап 28: видео в сообщениях и личное удаление чата

Что изменено:
- одно MP4/WebM-видео до 50 МБ можно отправить в личном чате или группе «Поболтаем»;
- видео показывается встроенным проигрывателем без автозапуска;
- в меню личного чата добавлено действие «Удалить чат»;
- удаление действует только для текущего пользователя и не затрагивает собеседника;
- после нового сообщения диалог появляется снова, старая скрытая история не возвращается;
- группы удалить этим действием нельзя.

После распаковки:
1. Сделать резервную копию PostgreSQL.
2. В kazachiy-krug-server выполнить: npx prisma migrate deploy
3. Выполнить: npm run prisma:generate
4. Выполнить тесты сервера и клиента, затем сборку клиента.
